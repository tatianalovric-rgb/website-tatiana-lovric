# Tatiana Lovric Global Consulting

> **Where Law, Strategy & Global Vision Converge**

Sitio web corporativo y bilingüe (Español / Inglés) de **Tatiana Lovric Global Consulting**, firma internacional especializada en derecho corporativo, gestión ambiental, auditorías ISO 14001, compliance internacional y trazabilidad ESG.

---

## 🚀 Soluciones y Plataformas Integradas

- **Visado de Impacto Verde:** Evaluación y certificación de viabilidad ambiental y criterios sostenibles ([visado-impacto-verde.onrender.com](https://visado-impacto-verde.onrender.com)).
- **Pasaporte de Sostenibilidad ESG:** Sistema integral de diagnóstico, medición, reporte y trazabilidad bajo estándares ESG ([pasaporte-sostenibilidad.onrender.com](https://pasaporte-sostenibilidad.onrender.com/#/planes)).

---

## 📂 Estructura del Proyecto

```
├── index.html        # Estructura semántica, marcado bilingüe (data-i18n) y JSON-LD Schema.org
├── styles.css        # Hoja de estilos (paleta oficial #0A0D14, #10B981, #2563EB, #F59E0B)
├── main.js           # Motor de traducción (ES/EN), control de WhatsApp y acordeones FAQ
├── robots.txt        # Reglas de indexación y permisos para rastreadores de IA (GPTBot, ClaudeBot, etc.)
├── sitemap.xml       # Mapa del sitio con anotaciones hreflang (es/en)
├── diseño.md         # Guía de estilo visual y especificaciones de marca
├── logo.png          # Logotipo oficial
└── serve.js          # Servidor estático local para pruebas
```

---

## 🛠️ Ejecución Local

Para levantar el servidor de pruebas en tu entorno local:

```bash
node serve.js
```

Accede a `http://localhost:3000` en tu navegador.
