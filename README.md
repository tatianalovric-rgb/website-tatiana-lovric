# Terranova Global Solutions

> **Where Law, Strategy & Global Vision Converge**

Sitio web corporativo y bilingüe (Español / Inglés) de **Terranova Global Solutions**, firma internacional especializada en consultoría jurídica corporativa, gestión ambiental, auditorías ISO 14001/HSEQ, compliance transfronterizo y trazabilidad ESG, bajo la dirección ejecutiva de **Tatiana Lovric** (Socia Directora / Lead Counsel).

---

## 🚀 Soluciones y Plataformas Tecnológicas del Ecosistema Terranova

- **Visado de Impacto Verde:** Evaluación y certificación de viabilidad ambiental y criterios sostenibles ([visado-impacto-verde.onrender.com](https://visado-impacto-verde.onrender.com)).
- **Pasaporte de Sostenibilidad ESG:** Sistema integral de diagnóstico, medición, reporte y trazabilidad bajo estándares ESG ([pasaporte-sostenibilidad.onrender.com](https://pasaporte-sostenibilidad.onrender.com/#/planes)).

## 📂 Estructura del Proyecto

```
├── index.html        # Estructura semántica, marcado bilingüe (data-i18n) y JSON-LD Schema.org
├── styles.css        # Hoja de estilos con paleta Terranova (oro pulido & cian tecnológico)
├── main.js           # Motor de traducción (ES/EN), control de WhatsApp (+58 412 331 2425) y acordeones FAQ
├── robots.txt        # Reglas de indexación y permisos para rastreadores de IA (GPTBot, ClaudeBot, etc.)
├── sitemap.xml       # Mapa del sitio con anotaciones hreflang (es/en) y canonicals actualizadas
├── diseño.md         # Guía de estilo visual y especificaciones de marca
├── logo.png          # Logotipo oficial con esfera orbital y filamentos dorados/cian
├── vercel.json       # Configuración de despliegue y headers de seguridad para Vercel
└── serve.js          # Servidor estático local para pruebas
```

---

## 🛠️ Ejecución Local

Para levantar el servidor de pruebas en tu entorno local:

```bash
node serve.js
```

Accede a `http://localhost:3000` en tu navegador.
